# Дерево прошивки Leshy2

*Читать на: [English](firmware-tree.md) · **Русский***

Глубокая дока к [этапу 3](../README.ru.md#3-дерево-прошивки). Превращает [дерево возможностей](capability-tree.ru.md) (меню *что устройство могло бы уметь*) в **форму прошивки** — домашний лаунчер, приложения и разбиение каждого на **main · Настройки · Лаборатория**, по частоте обращения. Это карта, которую [этап 8](../README.ru.md#8-экраны-и-фичи) потом прорабатывает поэкранно.

## Граница Лаборатории (единственное правило)

Каждое приложение делит функции натрое:

- **Main** — всё, что можно безопасно направлять на мир: пассивный скан / приём / декод / детект, чтение и запись **своих** носителей и **легитимный TX по своей власти** (LoRa / Meshtastic / APRS на своём позывном, голос рации, ИК по своей технике, replay сигнала, который *ты* снял со *своего* устройства).
- **Настройки** — конфиг и инфра приложения: драйверы, полосовые фильтры, идентичность/ключи, DSP, предпочтения (региональные лимиты берутся из глобального визарда).
- **Лаборатория** — **только своё железо / изолированное пространство.** Правило не «передаёт ли» — легитимная связь тоже передаёт. **Лаба = передача, чей эффект ложится на железо или спектр, которыми ты не владеешь и не уполномочен тестить**: атака, имперсонация, jam, DoS, флуд, инъекция, спам, брутфорс и replay *чужого* сигнала. Приёмные приложения (Radio RX, GPS) несут намеренно **пустую Лабу** с пометкой — не молчаливый пробел.

Каждый инструмент Лабы стартует **разоружённым** и вооружается за [ARM-интерлоком](#глобальная-обвязка-и-safety); аппаратный **STOP** и **long-BACK** паник-килл живы с любого экрана всегда.

## Install-соглашение (не во вред)

Флоу первой загрузки, до того как доступно любое радио — как в [esp32-leshy](https://github.com/anton-vinogradov/esp32-leshy):

1. **Выбор языка.**
2. **Соглашение** — полноэкранная клятва (*не во вред; передавать только на оборудовании, которым владеешь или на тест которого есть письменное разрешение; соблюдать региональные лимиты мощности / duty*). Нужно **докрутить до конца**, чтобы разблокировать кнопки; **hold-to-confirm** OK = Принять, F1 = Отклонить. Отклонить → устройство выключается; до записи о принятии домашнее меню заперто на **Настройки + Выключить**.
3. **Визард региона / compliance** — выбрать регион, что ставит лимиты мощности TX, duty-лимитер и band / DFS-lockout, чтобы устройство не могло передавать до выбора региона.

Принятие пишется в NVS, **проштамповано версией прошивки, выбранным регионом и набором присутствующих Lab-инструментов**. Пере-показ: после factory reset и — ключевое — **всякий раз, когда набор Lab / атакующих инструментов вырос** относительно штампа (новая цель jam или режим спама заново триггерит согласие, не только major-бамп версии). Каждый power-cycle первый вход в **любую** Лабу показывает однострочный ре-аффирм (*«Только авторизованные цели — STOP гасит TX»*, один OK). Safe-default после любого reset / brownout: все радио выкл.

## Глобальная обвязка и safety

Всегда рядом, вокруг каждого приложения:

- **Домашний лаунчер** — сетка приложений по частоте; скролл энкодером, `F1`/`F2` квик-слоты, контекст-меню `OPTIONS`. Заперт на *Настройки + Выключить* до принятия соглашения.
- **Статус-бар** — код региона · индикатор TX-LIVE · активное радио / владелец TDD · батарея + заряд · GPS-fix · **часы (RTC)** · иконка **SD / USB**.
- **STOP** — гасит **весь TX** с высокоприоритетного пути, любой экран, любое состояние. **Long-BACK** — весь TX выкл **+ каждый Lab-инструмент разоружён** + safe-state, с любого экрана.
- **Меню `OPTIONS` (глобальное, с любого экрана)** — вкл. **Выключить** (чисто); низкий заряд → форс-выключение; watchdog / brownout → safe-state (все радио выкл).
- **Визард региона / compliance** (первый запуск, правится позже) → лимиты мощности TX, duty-лимитер, band / DFS-lockout.
- **BLE-клавиатура** (спаренный телефон, NimBLE HID host) для длинного текста в любом поле; экранная клавиатура — резерв.
- **ARM / DISARM интерлок** — каждый Lab-инструмент стартует разоружённым; ничего не передаёт до вооружения.

**Всегда-вкл фоновые сервисы** (не меню-приложения): **GPS-сервис** (fix в статус-баре, дисциплина RTC, авто гео-тег каждого захвата), **TDD-арбитр РЧ-сосуществования** (даёт одну эксклюзивную разнодиапазонную TX-цепь за раз — SA868 / LoRa / CC1101 / Wi-Fi; 3× nRF24 = один параллельный 2.4 ГГц-набор), **IPC линка S3↔C5** и **алерты детекта** (WS2812 LED / зуммер / GPS-тег / тост; настраивается в *Настройки → Алерты*).

## Кросс-приложенческие сессии

Кое-что пользователь делает через несколько приложений — им дают один вход, а не разбросанность:

- **Wardrive** (`F1`/`F2` квик-слот) — одно действие включает сканеры Wi-Fi + BLE + sub-GHz с GPS-тегом в один Wigle-лог. Самая частая многочасовая сессия.
- **HID Injection (BadBLE + BadUSB)** — один вход для обоих DuckyScript-payload'ов (общий парсер): по BLE или по USB-C. Лаба, разоружено, только авторизованный хост.
- **Quick-replay (своё, тегнутое)** — шорткат ретранслировать сигнал, который *ты* снял и пометил своим (sub-GHz / IR / ESB). Всё равно Лаба-разоружено + STOP, но короткий путь для частого случая своего пульта.

## Приложения (в порядке частоты)

Каждое: **Main** (можно направлять на мир) · **Настройки** · **Лаборатория** (только своё железо / изоляция).

### 1. Wi-Fi (2.4 + 5 ГГц)
*Первое, что открывают; обе полосы едины — выбираешь вид сети, не чип.*
- **Main** — скан AP / станций (2.4 + 5 ГГц) + обзор каналов + RSSI · снифф beacon / probe + сырой PCAP · waterfall загруженности / пакетрейта · **детектор** deauth + rogue-AP / evil-twin (защита) · инвентарь клиентов / скрытых SSID + сбор 5 ГГц probe · **пассивный снифф Zigbee / Thread / 802.15.4 + энергоскан** (C5, RX-only) · **детектор Drone Remote-ID** (Wi-Fi + BLE, с GPS-тегом) · сводный двухбэнд-обзор.
- **Настройки** — STA-подключение (авториз. сети; прошивка не вводит учётки) · MAC-спуф / рандом · регион / DFS-политика каналов · пейринг ESP-NOW Leshy↔Leshy · SoftAP web-UI / OTA · статус линка C5 (SPI3) · dwell / hop скана.
- **Лаборатория** — deauth / disassoc (точечный + широковещательный; не работает vs 802.11w/PMF) · флуды management-кадрами (beacon-спам random/clone/Rickroll, probe / auth / assoc) · Evil Portal · Evil Twin / rogue AP / Karma · консоль инъекции 802.11-кадров · снифф / спуф ESP-NOW · **5 ГГц deauth/spam — не проверено до [bring-up](../README.ru.md#11-bring-up-на-железе); откат на пассив.**

### 2. Bluetooth (BLE)
*Второе по обращаемости; adv-скан и детект трекеров — ежедневное.*
- **Main** — сканер рекламы (ext-adv / Coded-PHY) · оффлайн-база устройств (OUI + company-ID) + RSSI-радар близости · детектор AirTag / Find My + персон-трекеров (сталкинг) · снифф Continuity / типа устройства · перечисление GATT *(только свои / авторизованные — активный connect)* · wardriving / гео-лог + сырой adv-PCAP.
- **Настройки** — пейринг HID-host (нажатия с телефона = ввод текста) · фильтры скана / база OUI + company-ID · adv TX-мощность / интервал / PHY.
- **Лаборатория** — инъекция HID keyboard / media ([BadBLE](#кросс-приложенческие-сессии)) · proximity-pairing спам (Apple / Android Fast Pair / Windows Swift Pair / Samsung) · Sour-Apple краш-спам iOS (DoS) · эмуляция beacon Find My / AirTag · произвольный adv-broadcaster (имперсонация) · BLE connection-flood / GATT DoS.

### 3. Sub-GHz (CC1101)
*Классический daily-driver — пульты ворот / машин и сенсоры 433 / 868 МГц.*
- **Main** — RSSI-частотомер-охотник (грубо + точно) + частотомер · свип-RSSI спектр / waterfall · Read RAW (OOK) + авто-запись по RSSI-сквелчу · мультибэнд-хоппер скан-и-лог · декод статик-код + телеметрия сенсоров rtl_433 · распознание rolling-code (без клона) · библиотека сигналов (просмотр / тег) · шорткат **[quick-replay своего](#кросс-приложенческие-сессии)**.
- **Настройки** — SP4T 4-полосный фильтр + PLL · произвольный конфиг регистров CC1101 · региональные PATABLE-лимиты.
- **Лаборатория** — сырой replay (RAW TX) / эмуляция декод. протокола *(чужого сигнала)* · брутфорс фикс-кода / de Bruijn · replay плейлиста сигналов · CW / несущая тест-тон · узкополосный одноцелевой jam / реактивный jam.

### 4. NFC / RFID *(опциональный M5 RFID2-юнит)*
*Хедлайн работа с картами доступа — но всё приложение скрыто, пока не обнаружен опциональный Grove RFID2 (WS1850S). В базовой конфиге (без юнита) порядок ниже реформируется 1,2,3,5,6…*
- **Main** — обнаружение ISO14443A + разведка UID / ATQA / SAK + фингерпринт · дамп / чтение MIFARE Classic (ключи известны, свои карты) · чтение Ultralight / NTAG21x · парс NDEF · чтение / идентификация Amiibo · DESFire / ISO14443-4 APDU transceive · детект magic-карты (gen1a/gen2) · библиотека карт на SD.
- **Настройки** — проб присутствия юнита (hot-plug WS1850S) · словарь ключей + тайминг ридера.
- **Лаборатория** — словарная / nested-атака MIFARE Classic · запись / восстановление MIFARE · запись Ultralight / NTAG (вкл. PWD_AUTH) · сборка / запись NDEF · клон UID на magic-карту · wipe / format magic-карты · чтение EMV-контактлесс (privacy-гейт).

### 5. ИК (TX + RX)
*Быстрая частая утилита — захват, replay, универсальный пульт.*
- **Main** — **универсальный пульт — ТВ / медиа / кондиционер / проектор / аудио** (сверху: самое частое ИК-действие) · ИК-приём + декод + сырой захват · ИК-передача декод. команды / сырой replay *(по своим устройствам)* + выбор частоты несущей · импорт / экспорт `.ir` + библиотека на SD · **[quick-replay своего](#кросс-приложенческие-сессии)**.
- **Настройки** — управление базой кодов (своя сборка) · несущая / протокол по умолчанию.
- **Лаборатория** — TV-B-Gone универс. выключение (nuisance mass-off) · брутфорс-свип ИК-кодов.

### 6. РЧ-Спектр (nRF24 ×3)
*Параллельный 3-антенный 2.4 ГГц энерго-waterfall + MouseJack-разведка.*
- **Main** — 3-радио RPD энерго-спектр / waterfall / occupancy (параллельный свип) · оверлей энергии Wi-Fi-каналов · энерговид Zigbee / 802.15.4 (только энергодетект) · снифф ESB + поиск адресов · скан уязвимых MouseJack · снифф BLE-рекламы (adv-only) · 3-антенный RSSI-пеленг.
- **Настройки** — конфиг регистров / каналов / карты антенн nRF24 · CRC-фильтр (защита от ложняков).
- **Лаборатория** — инъекция нажатий MouseJack · снифф нажатий класса KeySniffer (только своё железо) · ESB replay / фейк-девайс / брутфорс адресов · спуф BLE-рекламы (через nRF24) · узкополосный jam / реактивный jam · несущая тест-тон / sweep-beacon / VSWR.

### 7. LoRa & Mesh (SX1262)
*Очень популярно тут — Meshtastic, APRS, тесты дальности. Легитимная связь по своей власти в main.*
- **Main** — LoRa P2P обмен (TX + RX) · Meshtastic-совместимый mesh-узел *(фазирован на поздний релиз)* · скан LoRa-спектра (пассив) + промискуитет-снифф / лог · тест линка / дальности (RSSI / SNR) · LoRa-APRS маяк / RX / iGate / диджипитер · LoRaWAN-узел (Class A/C) · обобщённый (G)FSK / RTTY / CW / AX.25 маяк · LoRa OTA / межблочная передача файлов.
- **Настройки** — band-plan региона + duty + лимиты мощности · PHY-дефолты (SF / BW / CR) · ключи / позывной / конфиг узла.
- **Лаборатория** — узкополосный одноцелевой LoRa / несущая jam · реактивный jam.

### 8. Radio RX (FM / КВ / SW — Si4732)
*Ежедневное слушание на DSP-приёмнике. Передачи нет — Лаба пуста.*
- **Main** — FM-вещание + RDS · AM (ДВ / СВ / КВ) · SSB (USB / LSB) + CW + синхро-AM · bandscope / свип-RSSI спектр · сканер + лог на SD · запись RX-звука (WAV) · декод CW / RTTY / SSTV / WEFAX.
- **Настройки** — настройка / DSP (полоса, seek, S-метр, AGC / аттенюатор, soft-mute, AVC, BFO / калибровка) · пресеты / band-plans · загрузка SSB-патч-блоба (пользовательский) · роутинг аудио-мукса + калибровка.
- **Лаборатория** — *(пусто — приёмная подсистема)*.

### 9. GPS & Навигация
*GPS-**сервис** работает всегда (fix в статус-баре, RTC, авто гео-тег) — это **приложение** = UI навигации, открывается реже.*
- **Main** — позиция / нав / вид спутников · лог трека / крошек (GPX / KML) · вейпоинты / геозоны · **индикатор GNSS-помех / спуфинга** (защита) · вход в лог wardriving ([кросс-сессия Wardrive](#кросс-приложенческие-сессии)).
- **Настройки** — конфиг u-blox (частота, констелляции, dynamic model) · AssistNow оффлайн-подсказки · time-sync / дисциплина RTC (GPS + NTP).
- **Лаборатория** — *(пусто — приёмное позиционирование)*.

### 10. УКВ-рация (SA868)
*Изредка — полудуплексный аналог-FM голос / APRS; лиц.-гейтованная легитимная связь, атак-листа нет.*
- **Main** — NFM голос RX + TX (≤2 Вт) · скан каналов / тонов CTCSS-DCS + carrier-busy / RSSI · ручной PTT-голос · тон-берст 1750 Гц / DTMF энкод + декод · APRS (AFSK1200) TX / RX / iGate + AX.25 KISS TNC · SSTV TX / fox-hunt маяк · **авто-ретрансляторы** — simplex parrot-репитер, кросс-бэнд релей *(лицензированное / авториз. использование — ID + duty; ретранслируют чужой звук)*.
- **Настройки** — канал / тон / сквелч / полоса / громкость · TX-мощность / duty / ID-лимиты + региональные caps (пресет PMR446).
- **Лаборатория** — *(пусто — лицензированная голосовая связь; каждый TX наследует STOP + региональные caps)*.

### 11. Система и хранилище
*Настройка и обслуживание, открывается редко.*
- **Main** — SD-файлменеджер + импорт / экспорт конфига + оффлайн-база устройств · хранилище захват / replay (sub-GHz + IR + ESB) с тегами / плейлистами · инфо / самотест · датчик заряда · энумерация Grove / M5 I²C-юнитов + hot-plug-детект.
- **Настройки** — дисплей / тема / статус-бар · ввод (тач / энкодер / кнопки / экранная клавиатура) · **Алерты / Детект** (по-детектору вкл/выкл + канал: LED / зуммер / GPS-тег / тост) · OTA (Wi-Fi / SD / C5 по SPI3) · USB-serial CLI + mass-storage (SD-как-диск) · питание / сон / гейтинг периферии + C5 · WS2812 LED + зуммер · аналог. аудио-роутинг (мукс / PAM8302 / jack-detect через PCA9555) · политика РЧ-сосуществования (TDD) · регион / compliance · factory reset + просмотр crash / core-dump + управление RTOS-задачами · about.
- **Лаборатория** — инъекция USB-HID клавиатуры ([BadUSB](#кросс-приложенческие-сессии)).

## За потолком (deferred / ceiling)

Не размещено — кремний или закон исключают (зеркалит [потолок дерева возможностей](capability-tree.ru.md#за-потолком-вне-scope)): захват WPA PMKID / EAPOL-хендшейка · полный 5 ГГц monitor+inject / assoc-auth-флуд · **широкополосное / full-band глушение** на любом радио (оставлен только узкополосный одноцелевой jam, в Лабе) · nRF24 как приёмник 802.11 / полного BLE · Bluetooth Classic / снифф со следованием за BLE-соединением / BLE-jam · HF-TX, VHF airband + погода (~162 МГц), 30–64 МГц, DRM · эмуляция / релей NFC / ISO15693 / FeliCa / 125 кГц LF / hardnested-darkside · дуплекс-репитер SA868 / цифровой голос · wideband SDR / аналитика Linux-класса / cellular. **Полный mesh Meshtastic** остаётся в scope, но фазирован на поздний релиз.
