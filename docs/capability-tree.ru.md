# Дерево возможностей Leshy2

*Читать на: [English](capability-tree.md) · **Русский***

Глубокая дока к [этапу 2](../README.ru.md#2-дерево-возможностей). Это **меню всего, что железо Leshy2 могло бы уметь** — перечислено из того, что делают опенсорс-аналоги на железе вроде нашего, сгруппировано по подсистемам. [Дерево прошивки](../README.ru.md#3-дерево-прошивки) строится *из* этого меню; реализовывать каждый лист оно не обязано.

Каждый лист несёт **реюз** (как берём код) и **гейт** (что ограничивает) — чтобы «дизайн с нуля, reuse по возможности» был планом, а не лозунгом.

## Как читать лист

- **Реюз** — как получаем код:
  - **заимствовать** — есть донор под permissive-лицензией; копируем/адаптируем.
  - **писать** — хорошего донора нет; пишем с нуля (часто тонкая обёртка над примитивом ESP-IDF/драйвера).
  - **идея** — концепт проверен, но единственный донор — copyleft; **реимплемент начисто, не копируем**.
- **Гейт** — что ограничивает лист: потолок **железа**, **safety**-интерлок или **legal/региональное** правило. `⛔` = лист **за потолком кремния** (вне scope; перечислены в конце каждой ветки).

## Лицензионная дисциплина (почему так много «идея»)

Наша прошивка — **MIT**. Код можно *копировать* только из permissive-источников — **MIT / BSD / Apache-2.0 / Unlicense / public-domain**. Три крупнейших ESP32-аналога — copyleft: **ESP32 Marauder = GPL-3.0**, **Bruce = AGPL-3.0**, **прошивка Flipper Zero = GPL-3.0**. Поэтому возможность, которую реализуют *только* они, — это **идея** (реимплемент начисто), а не **заимствовать** — копирование форсировало бы GPL на нашу прошивку. Где есть и permissive-донор (**ESP32-DIV** и **esp32-leshy**, оба MIT; **ESP-IDF** Apache-2.0; **RadioLib**, **SparkFun**-либы, **Arduino-IRremote**, **LVGL** MIT; **miguelbalboa/rfid** Unlicense) — **заимствуем** у него, а copyleft-проект держим только как референс.

## 1. 2.4 ГГц Wi-Fi (ESP32-S3, нативно)

Радио S3 работает с management-кадрами напрямую. Полный monitor+injection / захват WPA-хендшейка — за потолком.

| Возможность | Реюз | Гейт |
|-------------|------|------|
| Скан AP, перечисление станций/клиентов | заимствовать — ESP32-DIV, ESP-IDF `esp_wifi` scan (MIT/Apache) | — |
| Снифф beacon/probe, сырой promiscuous PCAP | заимствовать — ESP-IDF promiscuous + `pcap` (Apache), ESP32-DIV | по одному каналу (хоп); зашифрованные payload'ы непрозрачны |
| Монитор пакетрейта / загруженности канала | заимствовать — ESP32-DIV waterfall (MIT) | — |
| Детектор deauth-атаки (защита) | заимствовать — ESP32-DIV Deauth Detector (MIT) | — |
| Точечный + широковещательный deauth / disassoc | заимствовать — ESP32-DIV Deauther (MIT); Marauder/Bruce = референс-идея | legal: только авторизованно, региональные лимиты + STOP · **не работает против 802.11w/PMF (WPA3, большинство совр. WPA2)** |
| Флуды management-кадрами (beacon spam random/clone/Rickroll, probe-флуд, auth/assoc-флуд) | заимствовать beacon/probe (ESP32-DIV MIT); auth/assoc-флуд = **идея** (Bruce AGPL) | legal: загрязнение спектра / DoS — авторизованно, duty-лимит + STOP |
| Evil Portal (перехват учёток через captive-portal) | заимствовать — ESP32-DIV Captive Portal (MIT) | legal: фишинг — строго авторизованно; прошивка не эксфильтрует перехваты |
| Evil Twin, rogue/honeypot AP, Karma/probe-response | заимствовать twin/rogue (ESP32-DIV MIT); Karma = **идея** (MANA/Bruce) | legal: имперсонация + DoS — авторизованно, STOP |
| MAC-спуф / рандомизация; STA-подключение | писать — `esp_wifi_set_mac` / STA (Apache) | — |
| Примитив инъекции 802.11-кадров (TX-движок) | писать — ESP-IDF `esp_wifi_80211_tx` (Apache) | legal: гейтить каждого вызывающего (своё железо, лимиты, STOP) |
| **ESP-NOW** — линк Leshy↔Leshy; снифф / спуф | заимствовать линк (ESP-IDF Apache); снифф/спуф = писать над примитивом инъекции | линк — без гейта; снифф/спуф TX-гейт. Быстрая ближняя альтернатива LoRa P2P |
| Web-UI конфиг / OTA поверх SoftAP | заимствовать — WiFiDuck web UI, ESP32-DIV (MIT) | — |
| ⛔ Захват WPA PMKID / EAPOL-хендшейка | идея | **потолок:** захват хендшейка вне scope; крякать оффлайн из PCAP |

| MouseJack: скан уязвимых + инъекция нажатий | заимствовать — ESP32-DIV MouseJack (MIT); JackIt = референс-идея | legal: только письменная авторизация; TX-лимиты + STOP |

## 3. 5 ГГц Wi-Fi + 802.15.4 (агент ESP32-C5)

Тонкий агент C5 поверх [линка SPI3](link-protocol.ru.md). Скан / SoftAP / STA — нативный ESP-IDF (Apache); deauth/disassoc едут на патченом блобе `libnet80211`, что permissive-форки C5 (maxbrito500 Apache; AnvilBrain, MIT + ethical-use-ограничение) показывают на своём кремнии — **не проверено на нашем продакшн-C5 до bring-up ([§11](../README.ru.md#11-bring-up-на-железе))**. У C5 есть и нативное **802.15.4** (Zigbee / Thread), тут — только под пассивную разведку.

| Возможность | Реюз | Гейт |
|-------------|------|------|
| Скан AP (актив. non-DFS / пассив.), обзор каналов, RSSI-метр | заимствовать — ESP-IDF `esp_wifi` scan (Apache), AnvilBrain/maxbrito500 | **активный проб только на non-DFS UNII-1/3; на DFS 52–144 только пассивно** (у C5 нет радар-детекта) |
| Промискуитет-снифф (частичный monitor) + сбор probe | заимствовать — ESP-IDF promiscuous (Apache) | лоссово, одноканально, без radiotap; приватность: авторизованно |
| Перечисление клиентов; инвентарь beacon/скрытых SSID | идея (Marauder GPL) / писать | только авторизованные цели |
| Детектор deauth, детектор rogue-AP/evil-twin (защита) | писать | — |
| Deauth / disassoc | заимствовать — maxbrito500 (Apache); AnvilBrain = референс-идея (MIT + ethical-use-ограничение) | legal: авторизованно, региональные лимиты + STOP · **не проверено на продакшн-C5 — верификация на bring-up ([§11](../README.ru.md#11-bring-up-на-железе)); патч-блоб может не завестись → откат на пассивную разведку** · не работает против PMF |
| Beacon / probe spam | заимствовать beacon (AnvilBrain MIT); probe = писать | legal: злоупотребление спектром — авторизованно/лаб, лимиты, STOP |
| Evil-twin SoftAP, evil portal, Karma | заимствовать SoftAP (ESP-IDF Apache); portal/Karma = идея (GhostESP/Marauder) | legal: авторизованно, non-DFS канал под AP, STOP |
| STA-подключение | заимствовать — ESP-IDF STA (Apache) | авторизованные сети; прошивка не вводит учётки |
| **802.15.4 / Zigbee / Thread пассивный снифф + энергоскан** | заимствовать — ESP-IDF `ieee802154` promiscuous (Apache); парс Thread = OpenThread (BSD-3) | только RX / снифф — без присоединения к Zigbee/Thread-сети (это полный стек, вне scope) |
| ⛔ Полный 5 ГГц monitor+inject · PMKID/EAPOL · assoc/auth-флуд · wideband jam | идея | **потолок:** всё требует полной 5 ГГц-инъекции / захвата хендшейка / широкополосности — вне scope |

## 5. Sub-GHz (CC1101, 300–928 МГц, SP4T 4 полосы)

Один узкоканальный CC1101 за 4-полосным фильтром. RX/RSSI/сырой-захват — из esp32-leshy/DIV (MIT) + **RadioLib** (MIT). Библиотеки *декода* протоколов (Flipper, rtl_433) — copyleft → идея.

| Возможность | Реюз | Гейт |
|-------------|------|------|
| RSSI-частотомер-охотник (грубо+точно); частотомер | заимствовать — esp32-leshy, ESP32-DIV, RadioLib (MIT) | PLL покрывает только ~300–348 / 387–464 / 779–928 МГц; ближнее поле |
| Sequential-RSSI спектр / waterfall | заимствовать — esp32-leshy, ESP32-DIV (MIT) | один узкий канал, без IQ — свип-вид, не реалтайм |
| Read RAW (тайминг OOK) + авто-запись по RSSI-сквелчу | заимствовать — esp32-leshy, ESP32-DIV (MIT) | только RX; хранение ограничено RMT/SD |
| Мультибэнд-хоппер скан-и-лог | заимствовать — esp32-leshy (MIT) | последовательный dwell пропускает короткие сигналы между хопами |
| Декод статик-код протоколов · телеметрия сенсоров rtl_433 · распознание rolling-code (без клона) | идея — Flipper (GPL), rtl_433 (GPL-2) | только RX/декод; rolling-код одноразовый, не клонируется |
| Сырой replay (RAW TX) · эмуляция декодированного протокола | заимствовать raw replay (esp32-leshy MIT); эмуляция = идея (Flipper GPL) | TX: авторизованно, региональные PATABLE-лимиты + STOP |
| Брутфорс фикс-кода / de Bruijn | идея — Flipper/Bruce (GPL/AGPL) | активная TX-атака — строго своё железо/авторизованно |
| Библиотека сигналов / теги / плейлист-replay | заимствовать — esp32-leshy (MIT) | replay наследует TX-гейт |
| Произвольный конфиг CC1101; CW-тест-тон | заимствовать — RadioLib (MIT) | частота ограничена полосами CC1101; TX-лимиты + STOP |
| Управление SP4T-фильтром (инфра) | писать | 4 полосы + PLL-разрывы ограничивают покрытие |
| Одноканальный узкополосный jam; реактивный jam-по-детекту | писать — RadioLib carrier/CW TX (MIT) | legal: только узкополосно и по одной цели, авторизация + duty-лимит + STOP |
| ⛔ Full-band / широкополосный sub-GHz jam · настоящий wideband-реалтайм-SDR | идея | **legal/потолок:** wideband jam незаконен; CC1101 одноканален, не SDR |

## 9. NFC / RFID (опциональный M5 Grove RFID2-юнит, WS1850S, 13.56 МГц)

## За потолком (вне scope)

Сведено из листов `⛔` выше — то, что кремний (или закон) исключает, совпадает с [списком вне-scope](https://github.com/anton-vinogradov/esp32-leshy2#1-why-a-new-device--vision) репо железа:

- **Полный 5 ГГц monitor + injection** и любой **захват WPA PMKID/EAPOL-хендшейка** (2.4 или 5 ГГц) — ни у одного ESP32 нет Linux-стека Wi-Fi; крякать оффлайн из PCAP.
- **Широкополосное / full-band глушение** на любом радио — незаконно (US §333, EU RED). Узкополосный одноцелевой jam (nRF24/CC1101/SX1262) остаётся в scope, авторизованно + STOP.
- **Снифф BLE со следованием за соединением** и **Bluetooth Classic (BR/EDR)** — LE-контроллер S3 не может; радио Classic нет.
- **nRF24 как приёмник 802.11 или полного BLE** — только энергодетект.
- **Передача КВ/CB/шортвейв** — Si4732 только приёмник. **VHF airband / NOAA-погода (~162 МГц)**, разрыв **30–64 МГц** и **DRM** вне его настройки/DSP.
- **Эмуляция/релей NFC-карты**, ISO15693, FeliCa, 125 кГц LF и восстановление ключей hardnested/darkside — WS1850S только ISO14443A-ридер; крипто-атаки — Linux-класс.
- **Настоящий дуплекс-репитер SA868** и **цифровой голос (DMR/C4FM/dPMR)** — один полудуплексный аналог-FM модуль.
- **Непрерывный wideband-SDR / произвольный TX (класс HackRF)**, **аналитика класса aircrack/Kismet на устройстве**, **сотовая связь/GSM** — другой, куда более дорогой класс устройства.
