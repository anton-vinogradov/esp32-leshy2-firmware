# Прошивка Leshy2

*Читать на: [English](README.md) · **Русский***

**Прошивка для [Leshy2](https://github.com/anton-vinogradov/esp32-leshy2) — портативного мультидиапазонного РЧ-наладонника с открытым кодом, который собираешь сам.**

Leshy2 — двухчиповый полевой инструмент: зрелый мозг **ESP32-S3**, который ведёт всё, плюс сопроцессор **ESP32-C5** ради нативного **5 ГГц** Wi-Fi. Этот репозиторий — его **прошивка**: портируется из [esp32-leshy](https://github.com/anton-vinogradov/esp32-leshy) (форк [ESP32-DIV](https://github.com/cifertech/ESP32-DIV)), наращивается под новые радио и несёт 5 ГГц-агент C5 поверх линка S3↔C5. Железо — схема, PCB, BOM — живёт в репо [esp32-leshy2](https://github.com/anton-vinogradov/esp32-leshy2).

> 🛑 **Только своё железо.** Это учебный инструмент для security-исследований и радио. Применять только к сетям, устройствам и радио, которыми владеешь или на тест которых есть письменное разрешение. Радиозакон в разных странах разный — проверить и соблюдать его на тебе.

## 1. Видение и рамки

**🟡 Постановка.** Оживить [железо Leshy2](https://github.com/anton-vinogradov/esp32-leshy2) в прошивке: **портировать зрелую кодовую базу esp32-leshy (S3)**, а не переписывать; нарастить её под новые радио; добавить тонкий **5 ГГц-агент ESP32-C5** за узким **протоколом S3↔C5**; реализовать соглашения управления устройством и два его safety-блокера. Набор возможностей — тот, что задан в репо железа, [этап 2](https://github.com/anton-vinogradov/esp32-leshy2#2-what-it-must-do--capabilities); ничего сверх того, что реально умеет кремний, здесь не обещается.

**В рамках:** основная прошивка S3 (UI, дисплей + тач, все проводные радио, шины, SD / PCAP, нативный 2.4 ГГц Wi-Fi + BLE), 5 ГГц-агент разведки на C5, линк S3↔C5, порегиональные лимиты TX в прошивке и стенд эмуляции / тестов, работающий до появления железа.

**Вне рамок (те же потолки, что у железа):** полный 5 ГГц monitor + injection, захват WPA-handshake, аналитика уровня Linux, HF-передача, wideband SDR, cellular и wideband jamming. Почему каждое вне — см. репо железа, [этап 1](https://github.com/anton-vinogradov/esp32-leshy2#1-why-a-new-device--vision).

**Решения (залочены на входе, из [этапа «Прошивка»](https://github.com/anton-vinogradov/esp32-leshy2#9-firmware) дизайна железа).**

- **Портировать прошивку S3 из leshy, не переписывать.** Бо́льшая часть S3-стороны уже работает (UI, дисплей, проводные радио, шины, SD, 2.4 ГГц Wi-Fi + BLE); опереться на этот код и наращивать новую периферию вокруг него, а не с чистого листа.
- **C5 — тонкий агент 5 ГГц за узким протоколом S3↔C5.** S3 остаётся мозгом и держит весь UI; C5 делает только разведку 5 ГГц и отвечает по небольшому командно-событийному линку через SPI3 + DRDY — две кодовые базы остаются развязанными.
- **Корректное выключение — функция прошивки, а не мастер-тумблер.** Тумблер рвёт батарею мгновенно, поэтому незавершённый PCAP / лог повредится; **OPTIONS → Выключить** (и long-BACK) сбрасывает SD, паркует все радио, гасит S3 + C5 и показывает экран «можно щёлкать тумблер».
- **long-BACK / STOP гасит весь TX, поверх любого экрана.** Один общий обработчик — с аппаратной клавиши STOP или по long-BACK — глушит все передающие цепи без снятия питания.
- **Длинный текст набирается со спаренного телефона по BLE.** Места под встроенную клавиатуру нет; основной путь — BLE-компаньон, запасной — Wi-Fi captive-portal, офлайн-резерв — колесо символов на D-pad.

**Артефакты.** Этот README (дизайн). Сама прошивка идёт следом, этап за этапом.
